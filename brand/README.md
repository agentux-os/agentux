## The idea

**The swimmer.** A penguin, Linux's own animal, swimming fast; its wake is
drawn as water lines and bubbles. The penguin is the system, the water it moves
through is the work the agents do around it. The penguin is drawn in full Lime
and the wake in Lime at 42 %, so the animal reads first and the movement
second; the middle water line runs into the penguin's back, and a gradient
carries it from wake to body.

The mark comes from the original artwork, [`src/penguin.png`](src/penguin.png),
traced once into [`src/penguin.svg`](src/penguin.svg) by
[`src/trace.py`](src/trace.py) with each part named (body, belly, flipper, eye,
water lines, bubbles). Below 64 px the wake turns to noise, so small sizes use
the **compact mark**: the penguin alone, its back ending in a cut tail. The
wallpaper and banners put the full mark in a field of faint water currents.

The wordmark is set in [Martian Mono](https://github.com/evilmartians/mono)
(SIL Open Font License) at weight 720 with slightly tightened tracking, then
converted to outlines. Monospace, because AgentUX is built on terminal agents;
the outlines mean no SVG here needs the font installed.

## Files

Everything in `svg/`, `png/` and `art/` is generated by
[`src/build.py`](src/build.py); edit the script, not the outputs.

| File | Use |
|---|---|
| `svg/mark-lime.svg` | Mark on dark backgrounds (Ink or darker) |
| `svg/mark-compact-*.svg` | The penguin without its wake, for 64 px and below (`lime`, `moss`, `ink`, `white`) |
| `svg/mark-moss.svg` | Mark on light backgrounds |
| `svg/mark-ink.svg`, `mark-black.svg`, `mark-white.svg` | Single-colour mark: print, engraving, stamps, overlays on photos |
| `svg/icon.svg`, `png/icon-1024.png` (and 16 to 256) | App icon: the compact mark in Lime on an Ink tile with a transparent margin. The cockpit icon is built from it |
| `svg/favicon.svg`, `png/favicon-16.png`, `favicon-32.png` | Favicon: the compact mark larger, on a full-bleed Ink tile, for 16 to 32 px |
| `svg/avatar.svg`, `png/avatar-512.png` | Square avatar: the full mark on Ink, as in the original art (GitHub org, chat, social) |
| `svg/wordmark-*.svg` | Wordmark alone: `mist` on dark, `ink` on light, `black` and `white` single colour |
| `svg/lockup-dark.svg` | Horizontal lockup on dark: Lime mark, Mist wordmark |
| `svg/lockup-light.svg` | Horizontal lockup on light: Moss mark, Ink wordmark |
| `svg/lockup-black.svg`, `lockup-white.svg` | Single-colour lockup |
| `svg/social.svg`, `png/social-1280x640.png` | Repository social preview (GitHub, link cards) |
| `svg/banner-dark.svg`, `banner-light.svg` | Organisation profile banner (copied into the `.github` repo) |
| `art/wallpaper-dark.svg`, `art/wallpaper-light.svg` | Desktop wallpaper key art, 3840 × 2160. The Plasma wallpaper package in agentux-desktop is rendered from these |

## Colours

| Name | Hex | Role |
|---|---|---|
| Lime | `#c6f36b` | The accent. Mark on dark, focus, selection; cockpit `--accent`, Plasma `AccentColor` |
| Ink | `#0b0d10` | Dark background; the app icon's tile; cockpit `--bg` |
| Graphite | `#171b20` | Raised dark surfaces (cockpit `--surface-2`) |
| Mist | `#e7eaef` | Text and wordmark on Ink (cockpit `--text`) |
| Slate | `#949dab` | Secondary text on Ink (cockpit `--text-muted`) |
| Moss | `#4f7d0b` | The accent on light backgrounds: Lime is too light to read on white (cockpit light `--accent`) |
| Paper | `#f4f5f7` | Light background (cockpit light `--bg`) |

Lime is for marks, lines and small highlights, never for body text, and never
on white or Paper (contrast 1.3:1). On light backgrounds use Moss.

## Clear space and size

- Clear space around the mark and the lockup: at least the height of the
  wordmark's capital A on every side (for the mark alone, a quarter of its
  height).
- Minimum size: lockup 160 px wide on screen (30 mm in print); full mark
  96 px wide. Below that use the compact mark, and `favicon.svg` below 32 px.
- In the lockup the mark is 1.9 × the cap height and sits 0.55 × the cap
  height from the wordmark, centred on the capitals. Use the lockup files
  instead of re-assembling them.

## Don'ts

- Don't recolour the water lines individually or give each one a vendor
  colour: the wake is one movement. Vendor colours belong to the cockpit's
  session views, not the logo.
- Don't draw the wake at full strength or the penguin faded: the penguin is
  full colour, the wake 42 %. In one-colour print, keep the tint or drop the
  wake and use the compact mark.
- Don't put Lime on white or Paper; use Moss.
- Don't add glows, shadows or outlines to the mark, or gradients beyond the
  built-in one from wake to back.
- Don't rotate or mirror the mark; the penguin always swims to the right.
- Don't redraw, stretch or re-space the penguin or the wordmark; regenerate
  from `src/penguin.svg` instead.
- Don't set "AgentUX" in another typeface as a logo. In running text, write
  it as AgentUX (one word, capital U and X).
- Don't place the mark on busy imagery without the Lime tile or an Ink panel
  behind it.

## Boot splash (Plymouth)

A Plymouth theme should use:

- Background: Ink `#0b0d10` (Plymouth `Window.SetBackgroundTopColor` /
  `SetBackgroundBottomColor` 0.043, 0.051, 0.063).
- Logo: `png/mark-lime-256.png` (1x) or `png/mark-lime-512.png` (HiDPI),
  transparent background, centred. `svg/mark-lime.svg` is there for other
  sizes.
- Wordmark, if any: `svg/wordmark-mist.svg` rendered to PNG at the size
  needed (Plymouth cannot load SVG).
- Progress and spinner: Lime `#c6f36b` on Graphite `#171b20`. The
  water lines of the wake can become the progress indicator.
- Background art, if the theme wants more than a flat colour:
  `art/wallpaper-dark.svg` (render it to the screen size).

## Rebuilding

```sh
cd brand/src
curl -L -o MartianMono.ttf 'https://raw.githubusercontent.com/google/fonts/main/ofl/martianmono/MartianMono%5Bwdth%2Cwght%5D.ttf'
npm install                     # @resvg/resvg-js, for SVG to PNG
pip install fonttools pillow
python build.py
```

`src/penguin.svg` is committed, so `build.py` does not trace. Only after
changing the artwork in `src/penguin.png`:

```sh
pip install potracer numpy pillow
python trace.py                 # rewrites penguin.svg
python build.py
```
